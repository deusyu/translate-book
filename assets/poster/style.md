# Style Brief — translate-book 项目海报

- 目标与受众:GitHub / 社交平台上的开发者,3 秒内看懂"整本书 → 并行 AI 子代理 → 完整译本",并记住安装命令。
- 输出场景与画布:线上分享与 README 展示,竖版 3:4,`[720, 960]`。
- 一句话核心信息:把一整本书拆成块,交给 8 个并行子代理同时翻译,校验后合并成完整译本。
- 视觉概念/隐喻:「A → 译」——两本书之间的一次并行装订:墨黑原著在上,书页拆成碎块洒落,穿过一排代理节点后染成朱红,汇入底部朱红封面的巨字《译》。
- 主视觉焦点:纵向"扇出—扇入"流水线本身;缩略图记忆点 = 黑书 → 八条碎块通道的沙漏形 → 红书大字"译"。
- 海报级视觉动作(为何不是普通内容页):整个画布是一条连续的流场,颜色在代理节点带处翻转(墨黑碎块 → 朱红碎块),用颜色讲完"翻译"这件事;不是标题 + 卡片墙。
- 视觉 DNA:纸本米白底(书籍/出版物材质感),墨黑与印章朱红两级对比;结构图为主、文字为辅;左侧编辑轨道(01–04 步)提供密度,与中央留白的流场形成疏密对位。
- 主视觉媒介与候选比较:主题是 CLI 管线工具,没有可作为"证据"的实拍素材,核心关系是流程/并行结构,故以可编辑矢量结构图为主。比较过的两个结构草案:(A) 纵向扇出—扇入沙漏流场(书→碎块→节点→碎块→书);(B) 左右两本巨书 + 中间八股编织桥(横版)。选 A:竖版更适合海报分发,纵向重力方向与"拆散—落下—汇合"的叙事一致,颜色翻转的表达在纵向更清晰;B 的横向编织在缩略图里易读成装饰纹样,放弃。
- 阅读顺序与构图:顶部品牌与标题 → 黑书(输入)→ 扇出碎块 → 代理节点带(虚线术语表轨贯穿)→ 朱红碎块扇入 → 校验闸口 → 红书《译》(输出)→ 格式行 → 安装命令 → 页脚。左轨 01–04 与各段对齐,支撑细节阅读。
- 配色与角色:纸白 `#F4EFE4`(底,纸张);墨黑 `#211B14`(原文、结构、正文);朱红 `#BF3A25`(译文、印章、强调,来自中文书印章朱砂);深朱 `#8E2A17`(红书书脊);暖灰 `#857964`(注释);浅沙 `#D9CFBA`(细规线)。
- 中英文字体与层级:中文思源宋体(标题 46 / 轨道标题 14 / 正文注释 9–13,出版物宋体气质);英文展示字 Oranienbaum(kicker 与步骤编号,古典高对比衬线,呼应"A");安装命令用精品点阵体(终端点阵感)。共三族。
- 图片选择与处理:无位图素材,全部矢量与文字,保证可编辑且仓库体积最小。
- 图形/连线语言:扇出扇入用平滑 S 曲线(细墨线 / 细朱线),碎块为微旋转的小矩形书页;代理节点 = 纸白圆 + 朱红芯;术语表 = 一条贯穿八个节点的朱红虚线轨;校验闸口 = 两枚墨色闸块 + 旁注 SHA-256。
- 信息密度、留白与对齐:中央流场保持大量纸面呼吸;密度集中在左轨与页脚;所有文字左缘对齐 56px 网格,图区轴线 x=436。
- 要避免的套路:圆角卡片墙、荧光科技风、黑底霓虹仪表盘、无意义图标矩阵、假出版物档案编号。
- 最可能退化成的样子(质检时对照):普通技术报告流程图(一排圆角框 + 细箭头)。若缩略图只剩标题和方框,重构流场而不是微调字号。

## 英文版变体(README 用)

`translate-book-poster-en.pptd` + `pages/poster-en.page`,几何布局与中文版一致,差异仅在文案与头部排版:

- 标题改为两行 Oranienbaum 44px:"A whole book, / translated in parallel.",与黑书上的"A"呼应;描述压成单行 11.5px。
- 输入格式标签("PDF · DOCX · EPUB")从书上方的独立说明移到黑书内部。
- 左轨标题为动词序列:Convert · split / Translate ×8 / Verify · resume / Merge · build(13px,规线加宽到 144,虚线轨起点右移到 212,避免与英文标题尾部相碰)。
- 红书保留巨字《译》与印章——对英文读者直观传达"翻译成另一种语言",副标 "WHOLE BOOK · TRANSLATED"。
- 英文海报嵌入 `README.md`,中文海报嵌入 `README.zh-CN.md`(两个 README 需同步维护)。
